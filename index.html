Bienvenue

MyBiblio est une petite application front‑end qui vous permet de gérer vos livres et vos étagères en utilisant le stockage local (localStorage). Utilisez le menu pour ajouter un livre, afficher la liste par étagère, ou rechercher dans votre bibliothèque.

  • Ajouter un livre
  • Voir les livres par étagère
  • Rechercher

Note

Les données sont stockées localement dans votre navigateur. Pensez à utiliser Exporter si vous souhaitez conserver ou transférer votre bibliothèque.
